# Hybrid Book Recommendation System with Neural Networks

## 1. Описание проекта

Итоговый проект по разработке гибридной рекомендательной системы книг на основе датасета Goodbooks-10k.

**Цель проекта:** объединить классические рекомендательные алгоритмы с нейросетевой архитектурой, повысить качество персонализации и исследовать баланс между релевантностью и разнообразием рекомендаций.

Проект реализован на Python в Google Colab.

## 2. Датасет

**Источник:** [Goodbooks-10k](https://www.kaggle.com/datasets/zygmunt/goodbooks-10k)

- 10 000 книг.
- 53 424 пользователя.
- 979 478 взаимодействий после удаления дубликатов.
- 793 929 взаимодействий в обучающей выборке.

Данные содержат пользовательские оценки, информацию о книгах и тематические теги.

## 3. Реализованные модели

В проекте использованы следующие подходы:

1. **Popularity-Based** — рекомендации наиболее популярных книг.
2. **Content-Based Filtering** — текстовые профили книг, TF-IDF и косинусное сходство.
3. **Item-Based Collaborative Filtering** — сходство книг на основе пользовательских оценок.
4. **TruncatedSVD** — матричная факторизация с 40 скрытыми факторами.
5. **Hybrid Recommendation System** — объединение классических алгоритмов.
6. **Optimized Hybrid + MMR** — улучшенное ранжирование с балансировкой разнообразия.
7. **Neural Collaborative Filtering (NCF)** — нейросетевая модель на PyTorch.
8. **Neural Hybrid + MMR** — объединение классического гибрида, нейросети и механизма разнообразия.

## 4. Расширенные признаки

**Признаки пользователей:**
- Средний рейтинг.
- Количество оценок.
- Уровень активности.
- Логарифмическая активность.

**Признаки книг:**
- Средняя оценка.
- Количество оценок.
- Стандартное отклонение рейтингов.
- Популярность.
- Тематические категории.

**Признаки взаимодействий:**
- Сходство книги с историей положительных оценок пользователя.
- Прогнозы классической SVD-модели.
- Прогнозы нейросетевой модели.

## 5. Нейросетевая архитектура NCF

Реализована модель Neural Collaborative Filtering на PyTorch.

**Архитектура:**

- User Embedding: 24.
- Book Embedding: 24.
- Объединение эмбеддингов.
- Полносвязные слои: 64 → 32 → 1.
- Функция активации ReLU.
- Выходной рейтинг в диапазоне от 1 до 5.

Количество обучаемых параметров: **1 527 425**.

Обучение проводилось в течение трёх эпох с использованием Adam и MSELoss.

Лучший Validation RMSE: **0.8878**.

## 6. Гибридная архитектура

Разработан процесс формирования рекомендаций:

1. Загрузка и предобработка данных.
2. Обучение классических и нейросетевой моделей.
3. Генерация кандидатов из четырёх классических моделей.
4. Добавление расширенных признаков.
5. Адаптивное взвешенное ранжирование.
6. Интеграция прогнозов NCF.
7. Переранжирование с помощью MMR.
8. Исключение уже оценённых книг.
9. Выдача Top-N рекомендаций.

Веса классических компонентов зависят от активности пользователя.

## 7. Результаты экспериментов

Финальное сравнение выполнено на выборке из 100 пользователей. Книги с оценкой ≥ 4 считались релевантными.

| Model | Precision@5 | Recall@5 | nDCG@5 |
|---|---:|---:|---:|
| Content-Based | 0.054 | 0.0826 | 0.0761 |
| Neural Hybrid + MMR | 0.054 | 0.0701 | 0.0741 |
| Hybrid | 0.050 | 0.0782 | 0.0685 |
| Optimized Hybrid + MMR | 0.052 | 0.0601 | 0.0676 |
| SVD | 0.002 | 0.0011 | 0.0034 |
| Popularity | 0.002 | 0.0033 | 0.0023 |
| Item-Based CF | 0.000 | 0.0000 | 0.0000 |
| NCF | 0.000 | 0.0000 | 0.0000 |

### Анализ результатов

Лучшее качество Top-5 рекомендаций показала Content-Based модель.

Нейросетевой гибрид занял второе место по nDCG@5 и улучшил результат оптимизированного гибрида с 0.0676 до 0.0741.

Самостоятельная NCF не обнаружила релевантных книг среди Top-5 на выбранных тестовых пользователях, однако её прогнозы оказались полезны для совместного ранжирования.

Оптимизация классического гибрида улучшила результаты на валидации, но не обеспечила аналогичного улучшения на финальной выборке.
